# Controle de Acesso IoT — IFSP-PEP

Sistema modular de controle de acesso e gerenciamento de salas desenvolvido como Trabalho de Conclusão de Curso no **IFSP Campus Presidente Epitácio**. Combina autenticação biométrica (ZN-53X), leitura NFC/RFID e comunicação MQTT para oferecer controle de portas em tempo real via portal web.

## Visão geral

A solução é composta por quatro camadas que se comunicam via HTTP REST e MQTT:

| Camada | Tecnologia | Função |
|---|---|---|
| **Portal Web** | React 19 · TanStack Router · Tailwind CSS | Interface de administração e monitoramento |
| **Backend API** | Fastify · Drizzle ORM · PostgreSQL | Lógica de negócio, autenticação e persistência |
| **Broker MQTT** | Node.js · Aedes | Ponte entre controladores físicos e o backend |
| **Firmware** | ESP8266 / ESP32 · C++ (Arduino) | Controlador instalado em cada porta |

## Fluxo principal de acesso

```
Usuário apresenta credencial (digital/NFC)
        │
        ▼
ESP8266 → MQTT → Broker (Aedes)
        │
        ▼
POST /iot/access → Backend (Fastify)
        │
        ├── Busca controlador → obtém roomId
        ├── Identifica usuário pela credencial
        └── Verifica permissão (4 níveis)
                │
                ├── GRANTED → registra log + enfileira UNLOCK
                └── DENIED  → registra log + feedback negativo
        │
        ▼
Broker publica door/{id}/access-result
        │
        ▼
Fechadura aciona relé (GRANTED) ou sinaliza negação (DENIED)
```
