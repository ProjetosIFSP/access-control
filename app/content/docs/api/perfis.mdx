---
title: Perfis de Acesso
description: Endpoints para criação, listagem, atualização e exclusão de perfis de acesso, além de gestão de permissões e vínculos com usuários.
---

Perfis são agrupamentos de permissões reutilizáveis. Em vez de conceder permissões individualmente a cada usuário, você cria um perfil (ex: "Docente", "Técnico de TI") e vincula múltiplos usuários a ele. Todos os endpoints exigem autenticação de administrador.

---

## Listar perfis

```http
GET /profiles
```

**Auth:** ✅ Administrador

**Resposta `200 OK`:**

```json
[
  {
    "id": "01951234-abcd-7000-8000-000000000010",
    "name": "Docente",
    "createdAt": "2025-01-10T08:00:00.000Z"
  },
  {
    "id": "01951234-abcd-7000-8000-000000000011",
    "name": "Técnico de TI",
    "createdAt": "2025-01-10T08:05:00.000Z"
  }
]
```

---

## Criar perfil

```http
POST /profiles
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "name": "Docente"
}
```

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `name` | string | ✅ | Nome do perfil (deve ser único) |

**Resposta `201 Created`:**

```json
{
  "id": "01951234-abcd-7000-8000-000000000010",
  "name": "Docente",
  "createdAt": "2025-01-10T08:00:00.000Z"
}
```

**Erros:**

| Status | Quando |
|---|---|
| `409 Conflict` | Já existe um perfil com este nome |
| `400 Bad Request` | Campo `name` ausente ou inválido |

---

## Buscar perfil

```http
GET /profiles/:id
```

**Auth:** ✅ Administrador

**Parâmetros de rota:**

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `id` | UUID v7 | ID do perfil |

**Resposta `200 OK`:**

```json
{
  "id": "01951234-abcd-7000-8000-000000000010",
  "name": "Docente",
  "createdAt": "2025-01-10T08:00:00.000Z"
}
```

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil não encontrado |

---

## Atualizar perfil

```http
PATCH /profiles/:id
```

**Auth:** ✅ Administrador

**Body (todos os campos são opcionais):**

```json
{
  "name": "Docente Efetivo"
}
```

**Resposta `200 OK`:** objeto do perfil atualizado.

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil não encontrado |
| `409 Conflict` | Já existe outro perfil com o novo nome |

---

## Excluir perfil

```http
DELETE /profiles/:id
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

> ⚠️ A exclusão de um perfil remove todos os seus vínculos com usuários e todas as permissões associadas ao perfil (`profile_room_permission` e `profile_room_type_permission`). Os usuários não são excluídos — apenas perdem as permissões herdadas do perfil.

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil não encontrado |

---

## Relações do perfil

```http
GET /profiles/:id/relations
```

**Auth:** ✅ Administrador

Retorna todos os dados de relacionamento do perfil em uma única chamada: usuários vinculados, permissões por sala, permissões por tipo de sala e tipos de sala associados.

**Resposta `200 OK`:**

```json
{
  "users": [
    {
      "id": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8",
      "name": "Ana Souza",
      "email": "ana.souza@ifsp.edu.br"
    }
  ],
  "roomPermissions": [
    {
      "id": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c",
      "name": "Sala dos Professores"
    }
  ],
  "roomTypePermissions": [
    {
      "id": "01951234-abcd-7000-8000-000000000030",
      "name": "Laboratório de Informática"
    }
  ]
}
```

## Usuários do perfil

### Listar usuários vinculados

```http
GET /profiles/:id/users
```

**Auth:** ✅ Administrador

**Resposta `200 OK`:**

```json
[
  {
    "id": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8",
    "name": "Ana Souza",
    "email": "ana.souza@ifsp.edu.br"
  }
]
```

---

### Vincular usuário ao perfil

```http
POST /profiles/:id/users
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "userId": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8"
}
```

**Resposta `201 Created`:** objeto do vínculo criado.

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil ou usuário não encontrado |
| `409 Conflict` | Usuário já vinculado ao perfil |

---

### Desvincular usuário do perfil

```http
DELETE /profiles/:id/users/:userId
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

## Permissões do perfil

### Conceder acesso a uma sala

```http
POST /profiles/:id/room-permissions
```

**Auth:** ✅ Administrador

Concede ao perfil acesso a uma sala específica. Todos os usuários vinculados ao perfil passam a ter acesso à sala imediatamente (PERM-003).

**Body:**

```json
{
  "roomId": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c"
}
```

**Resposta `201 Created`:**

```json
{
  "profileId": "01951234-abcd-7000-8000-000000000010",
  "roomId": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c"
}
```

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil ou sala não encontrado |
| `409 Conflict` | Permissão já existe para este perfil e sala |

---

### Revogar acesso a uma sala

```http
DELETE /profiles/:id/room-permissions/:roomId
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

---

### Conceder acesso a um tipo de sala

```http
POST /profiles/:id/room-type-permissions
```

**Auth:** ✅ Administrador

Concede ao perfil acesso a **todas as salas de um determinado tipo**. Todos os usuários vinculados ao perfil passam a ter acesso imediatamente (PERM-004).

**Body:**

```json
{
  "roomTypeId": "01951234-abcd-7000-8000-000000000030"
}
```

**Resposta `201 Created`:**

```json
{
  "profileId": "01951234-abcd-7000-8000-000000000010",
  "roomTypeId": "01951234-abcd-7000-8000-000000000030"
}
```

**Erros:**

| Status | Quando |
|---|---|
| `404 Not Found` | Perfil ou tipo de sala não encontrado |
| `409 Conflict` | Permissão já existe para este perfil e tipo de sala |

---

### Revogar acesso a um tipo de sala

```http
DELETE /profiles/:id/room-type-permissions/:roomTypeId
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

---

## Exemplo de uso — perfil completo

O fluxo típico para configurar um perfil do zero:

```
1. POST /profiles
   → Cria o perfil "Docente"

2. POST /profiles/:id/room-permissions
   → Concede acesso à "Sala dos Professores" (PERM-003)

3. POST /profiles/:id/room-type-permissions
   → Concede acesso a todas as salas tipo "Laboratório" (PERM-004)

4. POST /profiles/:id/users  (ou POST /users/:id/profiles)
   → Vincula "Ana Souza" ao perfil

Resultado: Ana Souza agora acessa a Sala dos Professores
           e todos os Laboratórios do campus.
```
