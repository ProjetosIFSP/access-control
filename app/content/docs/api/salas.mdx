Endpoints para gerenciamento do espaço físico do campus: **salas**, **blocos** (prédios) e **tipos de sala**. A maioria dos endpoints exige autenticação de administrador, exceto o resumo público de salas.

---

## Salas

### Listar salas

```http
GET /rooms
```

**Auth:** ✅ Administrador

Retorna todas as salas com informações do bloco e estado atual da porta.

**Resposta `200 OK`:**

```json
[
  {
    "id": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c",
    "name": "Laboratório 101",
    "block": {
      "id": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
      "name": "Bloco A"
    },
    "type": {
      "id": "01951234-abcd-7000-8000-000000000030",
      "name": "Laboratório de Informática"
    },
    "doorState": "CLOSED",
    "isLocked": true,
    "lastStatusUpdateAt": "2025-07-01T12:00:00.000Z"
  }
]
```

---

### Resumo de salas por bloco

```http
GET /rooms/summary
```

**Auth:** Opcional

Endpoint público. Retorna todas as salas agrupadas por bloco com estado semântico em português. Quando autenticado, inclui informações adicionais de uso (usuário atual e último usuário).

**Parâmetros de query (opcionais):**

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `blockId` | UUID | Filtra por bloco |
| `typeId` | UUID | Filtra por tipo de sala |
| `state` | string | Filtra por estado: `aberta`, `fechada`, `alerta` |

**Mapeamento de estado:**

| `doorState` (interno) | `isLocked` | Estado retornado |
|---|---|---|
| `OPEN` | `false` / `null` | `"aberta"` |
| `CLOSED` | qualquer | `"fechada"` |
| `OPEN` | `true` | `"alerta"` (porta aberta forçadamente) |
| `UNKNOWN` | qualquer | `"alerta"` |

**Resposta `200 OK` (autenticado):**

```json
{
  "authenticated": true,
  "result": [
    {
      "block": {
        "id": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
        "name": "Bloco A"
      },
      "rooms": [
        {
          "id": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c",
          "name": "Laboratório 101",
          "typeName": "Laboratório de Informática",
          "state": "aberta",
          "lastStatusUpdateAt": "2025-07-01T12:00:00.000Z",
          "currentUser": {
            "id": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8",
            "name": "Ana Souza",
            "email": "ana.souza@ifsp.edu.br"
          },
          "lastUser": {
            "id": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8",
            "name": "Ana Souza",
            "email": "ana.souza@ifsp.edu.br"
          }
        }
      ]
    }
  ]
}
```

**Resposta `200 OK` (anônimo):**

```json
{
  "authenticated": false,
  "result": [
    {
      "block": {
        "id": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
        "name": "Bloco A"
      },
      "rooms": [
        {
          "id": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c",
          "name": "Laboratório 101",
          "typeName": "Laboratório de Informática",
          "state": "fechada",
          "lastStatusUpdateAt": "2025-07-01T12:00:00.000Z"
        }
      ]
    }
  ]
}
```

> Os campos `currentUser` e `lastUser` são **omitidos** para usuários não autenticados por razões de privacidade.

### Criar sala

```http
POST /rooms
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "name": "Laboratório 101",
  "blockId": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
  "roomTypeId": "01951234-abcd-7000-8000-000000000030"
}
```

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `name` | string | ✅ | Nome da sala |
| `blockId` | UUID v7 | ✅ | Bloco ao qual a sala pertence |
| `roomTypeId` | UUID v7 | ✅ | Tipo da sala |

**Resposta `201 Created`:**

```json
{
  "id": "cdea3efb-650d-4c8a-a9c0-8ee97d739f5c",
  "name": "Laboratório 101",
  "blockId": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
  "roomTypeId": "01951234-abcd-7000-8000-000000000030",
  "createdAt": "2025-07-01T10:00:00.000Z"
}
```

---

### Buscar sala

```http
GET /rooms/:id
```

**Auth:** ✅ Administrador

**Resposta `200 OK`:** objeto completo da sala com bloco, tipo e estado da porta.

---

### Atualizar sala

```http
PATCH /rooms/:id
```

**Auth:** ✅ Administrador

**Body (todos os campos são opcionais):**

```json
{
  "name": "Lab. de Redes 101",
  "blockId": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
  "roomTypeId": "01951234-abcd-7000-8000-000000000031"
}
```

**Resposta `200 OK`:** objeto da sala atualizado.

---

### Excluir sala

```http
DELETE /rooms/:id
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

> ⚠️ A exclusão de uma sala remove também todas as permissões associadas a ela e o vínculo com o controlador de porta.

---

### Relações da sala

```http
GET /rooms/:id/relations
```

**Auth:** ✅ Administrador

Retorna todos os perfis e usuários com acesso à sala em uma única chamada.

**Resposta `200 OK`:**

```json
{
  "profiles": [
    {
      "id": "01951234-abcd-7000-8000-000000000010",
      "name": "Docente"
    }
  ],
  "users": [
    {
      "id": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8",
      "name": "Ana Souza",
      "email": "ana.souza@ifsp.edu.br"
    }
  ]
}
```

---

### Atribuir perfil à sala

```http
POST /rooms/:id/profiles
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "profileId": "01951234-abcd-7000-8000-000000000010"
}
```

**Resposta `201 Created`:** objeto da permissão criada.

---

### Conceder acesso direto de usuário à sala

```http
POST /rooms/:id/users
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "userId": "7b3cf58e-353f-48de-b2fd-6f203d64d3f8"
}
```

**Resposta `201 Created`:** objeto da permissão criada.

---

### Revogar acesso direto de usuário da sala

```http
DELETE /rooms/:id/users/:userId
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

## Blocos

Blocos representam prédios ou alas do campus que agrupam salas.

### Listar blocos

```http
GET /blocks
```

**Auth:** ✅ Administrador

**Resposta `200 OK`:**

```json
[
  {
    "id": "1cf51c96-86a9-4fb3-b8e8-556a745d4423",
    "name": "Bloco A",
    "createdAt": "2025-01-01T00:00:00.000Z"
  }
]
```

---

### Criar bloco

```http
POST /blocks
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "name": "Bloco A"
}
```

**Resposta `201 Created`:** objeto do bloco criado.

**Erros:**

| Status | Quando |
|---|---|
| `409 Conflict` | Já existe um bloco com este nome |

---

### Atualizar bloco

```http
PATCH /blocks/:id
```

**Auth:** ✅ Administrador

**Body:**

```json
{
  "name": "Bloco A — Reformado"
}
```

**Resposta `200 OK`:** objeto do bloco atualizado.

---

### Excluir bloco

```http
DELETE /blocks/:id
```

**Auth:** ✅ Administrador

**Resposta `204 No Content`:** sem corpo de resposta.

> ⚠️ Não é possível excluir um bloco que ainda possui salas vinculadas.
