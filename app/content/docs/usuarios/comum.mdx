# Guia para Usuários

Bem-vindo ao sistema de controle de acesso do IFSP. Este manual vai te ajudar a entender como interagir com as portas equipadas com nossos controladores inteligentes.

## Como acessar uma sala

Dependendo da porta, você poderá utilizar diferentes métodos para se identificar:

### 1. Acesso via Biometria

Se a porta possuir um leitor biométrico (leitor de digital):
- Aproxime seu dedo previamente cadastrado no leitor.
- Aguarde o feedback visual (veja abaixo).

### 2. Acesso via RFID/NFC

Se a porta possuir um leitor de cartão/tag:
- Aproxime sua credencial (cartão ou chaveiro RFID) do leitor.
- Aguarde o feedback visual.

## Feedback Visual do Controlador

O controlador de porta emite sinais visuais (LEDs) para informar o status do seu acesso:

- **Acesso Liberado:** O LED verde acenderá ou piscará, e a fechadura destrancará, permitindo a abertura da porta.
- **Acesso Negado:** O LED vermelho piscará. Isso significa que você não tem permissão para entrar neste momento, ou sua credencial não foi reconhecida.
- **Sem Conexão:** Em caso de perda de conexão, a cor do LED pode se comportar de maneira diferente (geralmente indicando modo offline). Neste caso, as últimas credenciais aceitas ainda funcionarão de forma local.

## Verificando Seus Acessos

Se desejar verificar o histórico de suas próprias entradas e acessos, você poderá realizar o login no painel web, acessar o seu perfil e visualizar os relatórios correspondentes na seção de logs. Em caso de dúvidas sobre acessos negados, entre em contato com a administração.
